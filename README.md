# TypeFlow -  Typing-speed-test
This is a cool website where you can test out your typing speed while maintaining your accuracy. Fixed the algorithm and it should be much better now but when typing please watch your spaces between letters or else your accuracy will tank! and mistakes will increase! The website's name is TypeFlow and the whole concept of this website is inspired by various different typing websites like Monkeytype, Nitro type, etc. but I wanted to make something different, where they user can't make a mistake or else accuracy/wpm will drop. 

# Background
I was inspired by typing test websites like Monkeytype, and such and I've been practicing my typing speed for years and I have seen an improvement in my typing speed by using websites like Monkeytype and I'm consistently clocking over 100 WPM now. So, I wanted to make a website of my own and publish it to hackclub. 

# How to use
Click on this link to go test out your typing speed!! : https://type-flow-typing-speed-test.vercel.app/
